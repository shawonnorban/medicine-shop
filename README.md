# Medicine Shop

দ্রুত অনলাইন ঔষধের দোকান (বাংলাদেশ): স্টোরফ্রন্ট, API, ইনভেন্টরি ও (পরবর্তী ধাপে) অ্যাডমিন + POS।

| অংশ | প্রযুক্তি |
|---|---|
| `apps/storefront` | Next.js 15 (ISR, SSR), React 19 |
| `apps/admin` | React + Vite (অ্যাডমিন: অর্ডার, সেটিংস, ইউজার, অডিট লগ) |
| `apps/api` | Fastify 5, TypeScript, `postgres` driver, zod |
| `db/migrations` | PostgreSQL 16 (pg_trgm সার্চ, লেজার-ভিত্তিক স্টক) |
| `docker-compose.yml` | Postgres, Redis, Meilisearch (Redis/Meilisearch পরের ধাপে ব্যবহৃত হবে) |

## চালানোর নিয়ম

```bash
cp .env.example .env
docker compose up -d postgres
pnpm install
export DATABASE_URL=postgres://medshop:medshop@localhost:5432/medshop
pnpm db:migrate
pnpm db:seed                                  # ২১টি নমুনা পণ্য
pnpm --filter @medshop/api db:seed:bulk 5000  # (ঐচ্ছিক) গতি পরীক্ষার জন্য ৫০০০ পণ্য
pnpm dev:api    # http://localhost:4000
pnpm dev:web    # http://localhost:3000
```

## API (ধাপ ১)

- `GET /health`
- `GET /v1/categories`
- `GET /v1/products?category=&company=&rx=&featured=1&q=&sort=name|price_asc|price_desc|discount&page=&limit=`
- `GET /v1/products/:slug` (প্যাক/ভ্যারিয়েন্ট, স্টক, মেয়াদ, বিকল্প ঔষধ)
- `GET /v1/search/suggest?q=` (প্রিফিক্স + টাইপো-সহনশীল)

### অর্ডার API (ধাপ ২)

- `POST /v1/otp/request` `{phone}` → `POST /v1/otp/verify` `{phone, code}` → ৩০ মিনিটের সাইন করা টোকেন
- `POST /v1/orders` `{token, name, phone, address, zone, items:[{variantId, qty}]}` (দাম সবসময় সার্ভার ডাটাবেস থেকে)
- `GET /v1/orders/:orderNo?phone=` · `POST /v1/orders/:orderNo/cancel` `{phone}`
- টেস্ট: `pnpm --filter @medshop/api test` (সিড করা ডাটাবেস দরকার)

SMS প্রোভাইডার এখনো স্টাব (`lib/otp.ts`); `OTP_DEV=1` হলে কোড রেসপন্সে ফেরত আসে। প্রোডাকশনে `APP_SECRET` বাধ্যতামূলক।

### অ্যাডমিন (ধাপ ৩ক)

```bash
STAFF_PASSWORD='<কমপক্ষে ১০ অক্ষর>' pnpm --filter @medshop/api staff:create you@example.com "আপনার নাম" admin
pnpm dev:api && pnpm --filter @medshop/admin dev   # http://localhost:3100
```

- লগইন: সেশন কুকি (`httpOnly`, `SameSite=Lax`, ১২ ঘণ্টা), ডাটাবেসে শুধু টোকেনের হ্যাশ। ৫ বার ভুল পাসওয়ার্ডে ১৫ মিনিট লক। প্রতিটি পরিবর্তনের অনুরোধে `x-requested-with` হেডার বাধ্যতামূলক (CSRF)।
- ভূমিকা: **অ্যাডমিন** সব কিছু · **ফার্মাসিস্ট** অর্ডার দেখা ও আপডেট · **ক্যাশিয়ার** অর্ডার দেখা।
- **Settings থেকে যোগ/এডিট/মুছুন:** ডেলিভারি এলাকা ও চার্জ ও ফ্রি-ডেলিভারির সীমা, পেমেন্ট পদ্ধতি, দোকানের তথ্য (নাম, ফোন, ঠিকানা, লাইসেন্স…), ক্যাটাগরি, কোম্পানি, ইউজার। ব্যবহারে থাকা জিনিস মোছা যায় না (অর্ডারের হিসাব ঠিক রাখতে), নিষ্ক্রিয় করা যায়। সব পরিবর্তন অডিট লগে।
- পাবলিক `GET /v1/config` স্টোরফ্রন্ট ও চেকআউটকে এই সেটিংস দেয় (ক্যাশ ~৩০ সেকেন্ড)।
- অর্ডারের অবস্থা ক্রমানুসারে: অপেক্ষমাণ → নিশ্চিত → প্রস্তুত → পথে → পৌঁছেছে। বাতিলে স্টক ফেরত। COD ডেলিভারিতে পরিশোধিত হয়।

### মেডিসিন ও স্টক (ধাপ ৩খ)

- **Admin → Medicines:** পণ্য এন্ট্রি (ব্র্যান্ড, জেনেরিক, কোম্পানি, ক্যাটাগরি, ফর্ম, স্ট্রেংথ, OTC/Rx, একাধিক প্যাক ও দাম, বারকোড, ছবি আপলোড)।
- **Admin → Purchases:** মাল গ্রহণ। প্রতিটি লাইন = ব্যাচ নম্বর + মেয়াদ + পরিমাণ + ক্রয়মূল্য। বারকোড স্ক্যান বা নাম লিখে খোঁজা যায়।
- **Admin → Stock:** প্যাকভিত্তিক স্টক, কম স্টক, মেয়াদ শেষ হচ্ছে, মেয়াদোত্তীর্ণ ইউনিট; ব্যাচ ধরে সংশোধন/রাইট-অফ/সাপ্লায়ারকে ফেরত।
- **ওয়েবসাইটে শুধু স্টকে থাকা ঔষধ দেখায়** (Store details → "Hide out-of-stock medicines")। স্টক শূন্য হলে তালিকা, সার্চ, সম্পর্কিত পণ্য ও ক্যাটাগরির সংখ্যা থেকে সরে যায়; সরাসরি লিংকে পেজ খোলে এবং "স্টকে নেই" দেখায়।
- স্টক গণনা: প্রতিটি ব্যাচের `qty_on_hand` ট্রিগার দিয়ে লেজারের সাথে মেলানো থাকে, তাই ৫,০০০+ পণ্যেও তালিকা ~৫০ মি.সে.। `stock_movements` ডাটাবেস স্তরেই মোছা/বদলানো নিষিদ্ধ।
- ছবি: JPG/PNG/WebP (ফাইলের আসল বাইট দেখে যাচাই), সর্বোচ্চ ৩ MB, `UPLOAD_DIR`-এ রাখা হয়।

### জেনেরিক লাইব্রেরী

- **Admin → Generic library:** প্রতিটি জেনেরিকের তথ্য: ড্রাগ ক্লাস, ইন্ডিকেশন, ডোজ, পার্শ্বপ্রতিক্রিয়া, নিষেধাজ্ঞা, ইন্টারঅ্যাকশন, গর্ভাবস্থা, সংরক্ষণ। যোগ/এডিট/মুছুন, "Missing info" ফিল্টার। ব্যবহারে থাকা জেনেরিক মোছা যায় না।
- Medicines ফর্মে জেনেরিক লিখলে লাইব্রেরী থেকে সাজেশন আসে, "fill empty text from library" দিয়ে খালি বিবরণ/ব্যবহারবিধি/সতর্কতা ভরা যায়। নতুন নাম লিখলে লাইব্রেরীতে নতুন এন্ট্রি তৈরি হয়।
- ওয়েবসাইট: প্রোডাক্ট পেজে "About <generic>" অংশ, `/generics` (A–Z তালিকা), `/generic/<slug>` (তথ্য + স্টকে থাকা সব ব্র্যান্ড)।
- স্টার্টার লাইব্রেরী (২৬টি সাধারণ জেনেরিক): `pnpm --filter @medshop/api db:seed:generics`। বারবার চালানো নিরাপদ, আপনার সম্পাদিত লেখা বদলায় না। **প্রকাশের আগে ফার্মাসিস্টকে দিয়ে যাচাই করান।**

## ডিজাইন সিদ্ধান্ত

- **স্টক = লেজার।** `stock_movements` শুধু যোগ হয়, কখনো বদলায় না। অনলাইন অর্ডার ও POS একই লেজারে লেখে, তাই ওভারসেল হয় না। মেয়াদোত্তীর্ণ ব্যাচ বিক্রয়যোগ্য স্টকে গণ্য হয় না।
- **ব্যাচ ও মেয়াদ** প্রতিটি ভ্যারিয়েন্টে, ভবিষ্যতে FEFO (আগে মেয়াদ শেষ হওয়া ব্যাচ আগে বিক্রি)।
- **লিস্টিং গতি:** পেজ আগে বেছে নিয়ে তারপর শুধু ওই ২৪টির স্টক হিসাব করা হয়। ৫,০০০+ পণ্যে লিস্টিং ~৩০–৫০ মি.সে.।
- **স্টোরফ্রন্ট** ISR-এ (৬০ সেকেন্ড রিভ্যালিডেট) স্ট্যাটিক HTML হিসেবে সার্ভ হয়। কার্ট ক্লায়েন্ট-সাইড (`localStorage`)।
- **অর্ডারে স্টক:** অর্ডার হওয়ামাত্র ব্যাচ লক করে, আগে মেয়াদ শেষ হবে এমন ব্যাচ থেকে লেজারে বিয়োগ লেখা হয়। বাতিলে উল্টো এন্ট্রি। একসাথে দুটি অর্ডার একই স্টক নিতে পারে না (টেস্ট করা)।
- Rx ঔষধে "কার্টে যোগ" নেই, প্রেসক্রিপশন ফ্লো (ধাপ ৪) না আসা পর্যন্ত অর্ডার করা যায় না।
